Southern Michigan road data for Roadar, covering Lansing and south with a buffer about 12 miles north of Lansing.

- **Download:** 83.9 MB; **installed storage:** 182.6 MB.
- **OSM snapshot:** September 3, 2026, 20:21:51 UTC.
- **Contents:** 805,037 road sections with geometry, road names, travel direction, and available explicit speed limits.
- **Scope:** offline road information. Map display, search, new routes, and live incident updates are separate capabilities.
- **Coverage:** explicit usable speed limits cover about 18.2% of included road distance; missing or unsupported limits remain unknown.

Download `southern-michigan.roadar.gz`, then import it in a compatible Roadar build under **Driving → Road downloads → Import road package from Files**. The manifest provides file size, installed size, and SHA-256 verification. This is a data release, not an iPhone app installer; GitHub's automatic source archives reflect the tagged repository checkpoint.
